Blinkit Sales Analysis | SQL + Power BI

This project analyzes Blinkit sales data using SQL and Power BI to uncover business and sales performance insights.

SQL Analysis:

Analyzed total and average sales by outlet type.
Compared sales by item type and fat content.
Analyzed sales across outlet establishment years.
Calculated item-level sales contribution percentages.
Used GROUP BY, WHERE, ORDER BY, aggregate functions, and subqueries.
Analyzed sales by location tier and product category.

Power BI Dashboard:

Total Sales by Outlet Type
Total Sales by Item Type
Average Sales by Fat Content
Sales by Outlet Size
Sales by Outlet Establishment Year
Rating analysis by Outlet Size
Interactive slicers for Fat Content, Establishment Year, and Item Type

Tools: SQL Server | Power BI | DAX | Power Query | Data Analysis | Data Visualization

Final Conclusion:
The analysis provides a clear view of Blinkit's sales performance across products and outlets. Supermarket Type 1 contributes the highest sales, while Fruits & Vegetables and Snack Foods are among the strongest product categories. Medium-sized outlets generate the highest sales, and sales performance varies across establishment years. The combination of SQL analysis and Power BI visualization helps transform raw sales data into meaningful business insights for understanding product and outlet performance
